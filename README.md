# OpenBEERS 2D/3D Three.js/WebGL visualization toolkit

This library provides an advanced toolkit for 2D/3D data visualization for the OpenBEERS web-platform.

This package was initially forked from [cityjson-threejs-loader](https://github.com/cityjson/cityjson-threejs-loader).

# Installation

This library is a module of the ```openbeers-client``` package, and is installed automatically when the client is built.

For development purposes, the package can be installed using:

```sh
git submodule update --init --recursive
npm install
```
